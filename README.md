# 星语 · Starlight Tarot

一个可以在手机浏览器里玩的塔罗牌小游戏。纯静态，零依赖，零构建。

## 内容

- **78 张牌面**，全部为程序化生成的 SVG（无外部素材、无版权风险）
- **156 段牌义**，温柔建议式文风，不做吉凶预言
- **抽牌流程**：心情 → 主题 → 洗牌 → 翻牌 → 逐字浮现的解读
- **每日一牌**：每天固定一张，翻过锁定
- **心情签到**：28 天热力图 + 连续天数
- **星座关联**：可选，只问月和日
- **记录本**：全部抽牌历史可回看
- **闯关地图**：3 章 30 关牌意判断题
- **分享海报**：Canvas 生成 1080×1440 竖图，长按保存

## 隐私

所有数据（抽牌记录、签到、闯关进度、星座）只存在玩家手机的
`localStorage` 里。**没有服务器，没有账号，不上传任何东西。**

## 本地运行

```bash
./tools/serve.sh
```

脚本会自动探测本机局域网 IP，并打印电脑与手机两个访问地址。

## 开发工具

| 路径 | 用途 |
|---|---|
| `/tools/cards.html` | 22 张大阿尔克那牌面预览 |
| `/tools/minor.html?suit=cups` | 按花色预览小牌 |
| `/tools/flip.html` | 翻牌动画方案对比 |
| `/tools/poster.html` | 分享海报生成预览 |
| `/tools/audit.html` | **牌面巡检**：逐张渲染成位图，检测空白牌与非法 XML |
| `./tools/audit.sh` | 命令行跑一次巡检 |

> `audit.html` 里 `?simulate=oldbug` 可模拟历史 bug，用来验证巡检本身是否可信。
